# 当前开发工作区的查询目标

本地开发阶段已获用户指定的唯一测试仓库：Yeahouse/teambrain-test，分支 main。

适用于当前工作区中“TeamBrain，介绍项目/查看进展”等省略仓库名的查询。不要默认读取 Skill 开发仓库作为团队工作数据，也不要跨项目发现成员。

连接：优先 github 的读取工具；如果认证失败，可使用已授权且验证过的 github_test_write 连接的 get_file_contents。该连接虽同时提供写入能力，查询功能只使用读取工具。

正常会话需能继承 MCP 令牌环境；无需把令牌放入 Skill。若此参考被用于其他团队，先由用户指定共享仓库并更新本绑定；不能沿用开发测试仓库当作真实项目。


## 与首次使用配置的关系

先按 setup-profile.md 运行 scripts/read-profile.py，检查当前用户 .config/teambrain/profile.json 中已确认的项目/成员，再考虑本次用户明确指定。本参考中的测试绑定仅属于用户已明确授权的当前开发上下文；新成员安装此源码时不得把示例仓库当作其已确认项目。缺少绑定时按 onboarding-setup.md 询问，不默认访问其他项目。

正式成员署名以本人确认及个人配置为准；测试成员 A 仅是虚构记录作者，不是默认身份。本地成员配置与GitHub认证、仓库绑定分别判断。
