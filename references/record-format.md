# R8 暂定记录格式

每条记录使用一个唯一目录：records/<submission-id>/record.md。
submission-id 首次创建后固定；重试继续使用同一 ID。

记录包含：提交 ID、作者、工作发生时间（带时区）、阶段、工作摘要、讨论要点、结论、未决问题、实际附件清单、外部链接、确认状态、同步及验证状态。

附件清单包含相对路径、字节数和 SHA-256。只有实际存在的文件才能列为已上传；失败项明确标记。外部链接包含名称和地址，未读取的内容标记未验证。

R8.1 先手工验证 Markdown 与真实附件，不提前引入数据库或强制 JSON 模式。此格式是 PoC 假设，不冒充完整 R7 结论。
