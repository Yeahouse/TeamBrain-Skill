# V3.2 项目与成员配置验收

统一使用现有scripts/read-profile.py及version=1配置。源代码不含测试项目名。测试须分清本地绑定、当前会话目标、GitHub MCP可调用及远端读写权限；介绍功能仍不读取配置。

| 场景 | 验证方式 |
| --- | --- |
| 首次无配置 | 隔离文件缺失，真实Skill生成首项目预览不保存；本地API测试确认保存及重读 |
| 已有单项目 | 兼容原无name字段的version=1，列表用owner/repo，默认字段不能变成当前会话授权 |
| 添加第二项目 | 保存前具体预览，人类确认后仅追加，备份原字节并校验其他项目及默认候选不变 |
| 切换 | 同名须owner/repo消歧，预览默认候选变化；本地API确认保存后两项目及署名均保留 |
| 不同署名 | 解析各项目返回对应member；修改一个项目不影响另一个，也不改远端历史 |
| 跨会话 | 当前真实Codex会话获批准保存一次，独立普通CLI从默认路径列出项目和署名；不改USERPROFILE/CODEX_HOME、不注入完整配置 |
| 旧项目防误用 | 新会话仅有历史项目时resolve需确认，不发起GitHub访问或误用其他项目作者 |
| 明确目标 | 当前指令仓库优先于会话旧目标，核对本地绑定，不自动更改默认项目 |
| 查询/同步衔接 | 二者调用相同resolve；实际只读读取已授权仓库，Work Sync预览显示项目名、仓库、分支和该项目署名 |
| 配置异常 | 缺文件和损坏文件用真实隔离文件；权限拒绝同时有真实隔离路径失败与受控单元测试，和正常默认路径可读性分别记录 |

真实个人配置变更必须在本会话向用户展示具体项目和署名，并取得明确批准。真实跨会话证据不能以--profile隔离文件或更换主目录替代。正式安装不可擅改；如有同名旧副本，测试临时选择开发版本并标明，不能称桌面入口已全部更新。

禁止远端写入。本地API受控故障测试不是GitHub实际故障，也不代表真实用户审批或新机器安装。保存计划摘要只用于锁定预览，不授予AI自行确认的权限。
