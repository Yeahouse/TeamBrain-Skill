# Project Progress Query 验收

只使用 Yeahouse/teambrain-test，五条指令分别在正常 Codex 会话执行。每例须保存回答和实际 MCP 事件，不能以预先生成的回答替代测试。当前测试数据是虚构数据，不新增远端夹具。

| 指令 | 可观察验收要求 |
| --- | --- |
| TeamBrain，介绍一下当前项目。 | 实际加载 Skill/引用文件并调用 MCP；从 project.md 或 README/记录说明项目；缺失正式项目定义时不补造目标和完整成员 |
| TeamBrain，现在项目进展如何？ | 读取阶段记录后概括已有结论及未决事项；不将虚构 PoC 说成实际团队项目已完成；提供来源 |
| TeamBrain，测试成员 A 做了什么？ | 依据作者字段关联工作与成果；不把仓库提交者等同工作作者 |
| TeamBrain，查看 R8.1 阶段的记录。 | 依据记录的阶段字段筛选；列正确记录及待验证事项，区分文件存在与状态字段快照 |
| TeamBrain，有哪些已提交的成果？ | 核对实际附件目录；返回记录下 sample.txt 及来源；不把 fixtures、README 或未核验外链当成果 |

额外关注：缺失根 artifacts/、links/ 或 project.md 不得触发自动补建；相同数据上的不同查询不得产生相互矛盾的成员/状态。工具错误或读取不完整时须声明覆盖范围。

实际结果与证据位置：docs/poc/project-progress-query/。未执行或失败用例不得记为通过。证据发布前检查临时下载授权参数及个人路径。
