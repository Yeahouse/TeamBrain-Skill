## 最小实现

- 沿用现有Skill与R7结构，新增功能引导路由及按需参考。
- 分别检查Skill识别、MCP连接、项目绑定、仓库读取、写工具/真实权限和成员确认。
- 未确认成员不阻断查询；写工具存在不自动认定可写；缺project.md不自动初始化。
- 用户自己的本地profile可复用已确认绑定和成员；不含凭据，未确认前不创建。
- 所有引导只读，新仓库、授权变更和真实写入另行确认。

## 实测

正常Codex会话依次测试：介绍功能、已确认项目与成员直接使用、未选项目、官方只读端点查询、真实缺project.md、原连接真实认证失败、无效URL、当前禁用GitHub连接。

临时禁用连接、改只读端点、当前消息明确不选项目属于可复现的运行配置测试，不冒充新机器或新PAT测试。每例保存Skill读取与实际工具/初始化错误证据；缺前提的引导场景可以没有仓库读取，但不能报告读取成功。
