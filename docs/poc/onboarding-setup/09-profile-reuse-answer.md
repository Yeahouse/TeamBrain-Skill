TeamBrain 有三个入口：

- **功能引导**：检查连接、项目绑定和成员配置。
- **项目查询**：读取已提交记录，回答项目进展、成员贡献、阶段与成果，并提供来源。
- **Work Sync**：从当前可见对话整理工作记录，先预览，明确确认后提交并回读核验。
