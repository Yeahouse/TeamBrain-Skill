TeamBrain 有三个入口：

- **功能引导**：检查连接，协助选择共享项目、确认成员署名。
- **项目查询**：读取项目记录，回答进展、成员工作、阶段和成果，并提供来源。
- **工作同步**：从当前可见对话整理成果，先展示预览，经你明确确认后提交并回读核验。
