## 实现

1. 入口识别自然语言同步请求；从当前可见对话提炼已完成工作、被否定方案、正式决定或探索状态。
2. 识别实际可读文本、外部链接与不支持成果，生成待确认清单；缺上下文先询问。
3. 本地辅助脚本生成稳定 ID、正文、候选附件指纹和待确认包，不联网、不赋予上传权限。
4. 修改后刷新预览并重新确认，取消不恢复。写前 MCP 查重，冲突停止；确认后仅提交批准文件。
5. 真实写入和固定提交回读后才报告成功；结果未知先查询远端。受控失败状态测试与真实 GitHub 故障分开记。

## 验收状态口径

- 正常讨论、最终方案修订、探索记录：先验证真实 Skill/MCP 和预览，再等用户针对具体包确认上传；当前不可标记完整同步通过。
- 修改/取消：同一真实会话连续用户消息验证稳定 ID 与排除项，最终取消后只读核对无新增。
- 重复：读取真实已存在 r81-20261021-001 及附件，报告已有，不创建新 ID、不调用写工具。
- 脚本受控测试覆盖唯一ID、稳定修订、取消、缺上下文、探索、附件字节与失败回执；不是 GitHub 实际网络故障测试。

最终交付包括源码、实际回答和调用事件、待确认包清单及已知限制。所有新开发修改仅本地，完成后另等用户确认提交推送。
